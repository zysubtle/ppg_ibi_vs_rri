# ppg_ibi_vs_rri

嵌入式 MCU 端单通道绿光 PPG-IBI 算法项目，用于低运动场景下逐搏输出 PPG 主峰到主峰的 IBI。

当前阶段为 M1：项目文档包、接口契约、数据契约、评估协议、里程碑计划和 PR 审查规则落库。M1 不实现算法、不提交真实生理数据、不引入生产依赖。
